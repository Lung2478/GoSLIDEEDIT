# GoSLIDEEDIT 快速上手指南 (Quick Start Manual — 繁體中文)

**GoSLIDEEDIT** 是一款單一免安裝執行檔、本機離線運作的 Windows 簡報編輯器。專為解決 **Microsoft PowerPoint** 與 **Google Slides** 之間交換 `.pptx` 檔案時常見的「字型跑版、圖表錯位、動畫失效」問題而打造。

> **隨附互動練習簡報**：啟動 `GoSLIDEEDIT.exe` 時，程式預設開啟的 **`QuickStart_GoSLIDEEDIT.pptx`（11 頁互動式手冊）** 即為本指南的實機練習場，建議邊看邊在畫布上點擊與拖曳操作。

## 1. 為什麼選擇 GoSLIDEEDIT（核心賣點總覽）

一般簡報在 Windows PowerPoint 做完後上傳到 Google Slides（或反向下載），經常發生文字換行溢框、長條圖標籤重疊、特殊轉場被靜默移除等問題。**GoSLIDEEDIT** 從底層結構解決這三大痛點：

| 常見痛點 | GoSLIDEEDIT 解決方案 | 實際效益 |
| :--- | :--- | :--- |
| **換台電腦或上傳雲端就字型跑版** | 內建 **15 款雙平台安全字型白名單** 與 **中英字體分開設定**，寫入標準雙軌字型標籤 | 同一段中英混排文字在 PowerPoint 與 Google Slides 皆不跳行、不走樣 |
| **圖表轉檔後數值錯位或不能改** | 商務圖表（長條／折線／圓餅／環圈）直接編譯為 **標準群組向量圖形** | 跨平台 0 像素誤差，且在雙方都能直接點擊微調與無損重編數據 |
| **外部簡報含 SmartArt / Excel 圖表會破圖** | 開啟時自動擷取 **2x 高清視覺快照** 保留原貌，並於右側提供 **「重製助手」** | 版面不缺漏，還能一鍵提取原始文字與數據轉為可編輯元件 |
| **需要上網登入或安裝龐大套件** | **單一執行檔 `GoSLIDEEDIT.exe`**，本機離線執行、無需安裝、零網路請求 | 隨身碟隨插即用，雙擊 `.pptx` 即於單一視窗多分頁秒開 |

## 2. 30 秒啟動與介面導覽地圖

### 啟動與開檔方式
* **直接啟動**：雙擊 `GoSLIDEEDIT.exe`，無需安裝即可啟動，預設載入 11 頁互動式快速上手簡報 `QuickStart_GoSLIDEEDIT.pptx`。
* **雙擊 `.pptx` 秒開**：將 `.pptx` 拖入視窗，或透過 Windows 檔案關聯開啟多份簡報時，會自動整合至**同一個視窗的不同分頁**，不重複開啟多個視窗。

### 工作區五大區域地圖

```text
+---------------------------------------------------------------------------------------+
| [1] 頂部導覽與格式列 (Top Navbar)                                                     |
| [SL] GoSLIDEEDIT | 側欄鈕 | 檔案 | 復原/重做 | 版面 | 主題 | 插入元件 | 字型 | 尋找 | 自動儲存 | 播放(F5) |
+------------------+------------------------------------------------+-------------------+
| 投影片縮圖|文字大綱|  [檔名1.pptx]  [檔名2.pptx *]  [+]            | (右側屬性欄標題)  |
+------------------+------------------------------------------------+-------------------+
| [2] 左側邊欄     | [3] 中央互動簡報畫布 (16:9 / 16:10 / 4:3)       | [4] 右側屬性檢查器|
|  - 投影片縮圖列  |                                                |  - 未選物件：     |
|    (拖曳重排頁序)|    +--------------------------------------+    |    比例/背景/轉場 |

|    (快速編修文字)|    |   (移近中心自動顯示智慧對齊紅線)     |    |    座標/樣式/圖表 |
|                  |    +--------------------------------------+    |    中英字體/動畫  |
|                  |------------------------------------------------|  - 多選(>=2個)：  |

+------------------+------------------------------------------------+-------------------+

+---------------------------------------------------------------------------------------+
```

1. **頂部導覽與格式列**：包含「檔案」選單（新增、開啟、儲存、列印與匯出）、套用版面、佈景主題、插入 5 大元件與圖表、中英字體選單與快速格式鈕 (`A-` / `A+` / `B` / `I` / 文字色)、尋找與取代 (`Ctrl+F`)、自動儲存開關、淺／深色主題切換、`中 / EN` 雙語切換與 **播放簡報 (`F5`)** 主按鈕。
2. **左側邊欄（`Ctrl+Shift+L` 收合／展開）**：頂部與右側 `.pptx` 分頁列水平齊平，可切換 **「投影片縮圖」**（視覺化瀏覽與排序）或 **「文字大綱」**（直接編輯各頁文字內容）。
3. **中央互動畫布與演講者備忘稿**：中性暖石板灰背景確保色彩判斷零干擾；畫布下方可隨時展開輸入演講備忘稿。
4. **右側屬性與動畫檢查器（`Ctrl+Shift+I` 收合／展開）**：依據目前選取狀態智慧切換為「投影片與轉場」、「單一元件詳細屬性／動畫」或「多選批次對齊與樣式」。
5. **底部狀態列**：左側切換三大檢視模式（標準編輯 / 投影片瀏覽網格 / 全螢幕播放），右側常駐 **跨平台相容性診斷器**、頁碼指示與 **`25% ~ 200%` 畫布縮放控制組（含 `Fit` 適應視窗）**。

## 3. 5 分鐘快速上手：完成第一份簡報

### 步驟 1：建立簡報與選擇版面
1. 點選左上角 **「檔案」 -> 「新增空白簡報」**（或按 `Ctrl+N`）。
2. 點選頂部工具列 **「套用版面」**，從 7 種標準結構（標題投影片、標題及內容、章節標題、兩項內容、僅標題、含圖說內容、空白版面）點選版面；**切換版面時會保留該頁已輸入的文字**，不會覆蓋心血。
3. 需要新增下一頁時，按工具列 **「新增投影片」** 或快捷鍵 `Ctrl+M`。

### 步驟 2：插入與編輯簡報內容
* **文字方塊與雙擊編輯**：點選工具列 **「文字方塊」** 新增方塊，**雙擊文字方塊**（或幾何圖形、表格儲存格）即可直接打字輸入；按下 `Esc` 可快速退出編輯狀態。
* **插入圖片**：支援 `.png`、`.jpg`、`.gif`、`.webp`、`.svg`，也可直接複製圖片後於畫布按 `Ctrl+V` 貼上。（`.webp` 與 `.svg` 於儲存 `.pptx` 時會自動轉為高解析 `.png`，確保雙平台不破圖）。
* **插入形狀、手繪多邊形、連接線、表格與圖表**：皆可直接從頂部工具列對應按鈕一鍵插入（點選「手繪多邊形」後可直接在畫布逐點點擊拉直線或按住左鍵自由手繪）。

### 步驟 3：拖曳排序投影片與快速換頁
* **快速換頁**：在主畫布或左側縮圖區**直接滾動滑鼠滾輪**，或使用 `Page Up` / `Page Down`（未選取元件時亦可用上下方向鍵）即可快速切換上一頁／下一頁。
* **無殘影拖曳排序**：在左側「投影片縮圖」、左側「文字大綱（按住卡片標題列）」或底部切換至 **「投影片瀏覽」** 網格檢視中，按住左鍵拖曳卡片超過移動門檻，看到亮橘插入指示線後放開即可完成頁序調整，且會**自動聚焦到剛移動的那一頁**並同步重編母片頁碼（按 `Ctrl+Z` 可單步復原）。

### 步驟 4：滑鼠右鍵雙層快捷選單
在畫布元件、畫布空白處、左側投影片縮圖或頂部檔案分頁上點擊**滑鼠右鍵**，即可叫出專屬情境選單：
* 對畫布元件按右鍵時，上方為 **浮動迷你格式列**（可即時調整中／英字體、字級、粗斜底線、對齊、文字色與填滿色，點擊後不會自動關閉選單方便連續微調），下方為剪下／複製／貼上／建立副本／圖層順序／置中對齊等常用動作。

### 步驟 5：播放簡報與儲存／匯出
1. **播放簡報**：按 `F5` 從第 1 頁播放，或按 `Shift+F5` 從目前這一頁播放。播放時可用滑鼠左鍵、空白鍵、方向鍵或滾輪推進動畫與換頁，按 `Esc` 隨時退出。
2. **儲存原檔**：按 `Ctrl+S` 儲存為跨平台標準 `.pptx`；也可開啟頂部右側 **「自動儲存」** 膠囊開關（僅針對已命名且未觸發格式正規化的本機檔案自動定時存檔）。
3. **單向交付匯出**：由 **「檔案」 -> 「匯出單向相容格式」**，可輸出多頁 `.pdf`、目前投影片 `.png` / `.jpg` / `.svg` 圖檔，或純文字 `.txt` 簡報大綱。

## 4. 六大特色賣點深潛

### 特色 1：15 款安全字型白名單與「中英字體分開設定」
許多商務簡報混排中文與英文數字時，常希望「中文用微軟正黑體（或標楷體），英文與數字自動用 Calibri（或 Georgia）」。
* **15 款雙平台安全字型**：
  * **繁體中文（3 款）**：`微軟正黑體`、`新細明體`、`標楷體`。
  * **西文與數字（12 款）**：無襯線 `Calibri`、`Arial`、`Arial Black`、`Verdana`、`Tahoma`、`Trebuchet MS`、`Impact`；襯線 `Georgia`、`Times New Roman`、`Cambria`、`Garamond`；等寬 `Courier New`。
* **四大介面皆支援中英分開設定**：在頂部 **「字型」** 下拉選單（可切換目標為「同時套用（中＋英）／中文字體／英數字體」）、右側屬性面板、滑鼠右鍵迷你工具列及「公版版面設定」視窗中，皆可獨立指定 **中文字體** 與 **英數字體**，或一鍵套用內建 4 組商務字體配對（如「微軟正黑體 + Calibri」、「標楷體 + Georgia」）。
* **本機系統字型彈性**：下拉選單同時列出 Windows 本機已安裝字型供本地設計或匯出 PDF/圖片使用；當儲存為 `.pptx` 時，系統會自動將非白名單字型安全映射回 15 款雙平台字型並綁定中英雙軌 XML 標籤，兼顧本機美感與跨平台零跑版。

### 特色 2：零變形商務圖表、手繪多邊形 (`Freeform Polygon`) 與 8 點磁吸向量連接線
* **群組向量商務圖表**：支援 **長條圖、折線圖、圓餅圖與環圈圖**。所有圖表底層皆編譯為 PowerPoint 與 Google Slides 原生支援的群組幾何形狀與文字框，並將結構化數據一併保存於檔案中。在雙平台開啟時 **0 像素誤差**，回到 GoSLIDEEDIT 開啟後依然可以點擊圖表，直接在右側「商務圖表設定」修改數值表格、圖表類型、顏色與資料標籤。
* **跨平台「手繪多邊形 (`Freeform Polygon`)」**：可由頂部「幾何圖形」選單、「連接線/箭頭」選單或畫布空白處右鍵選單啟動。支援 **單擊定點拉直線** 與 **按住左鍵自由手繪**（放開時自動平滑化為精簡頂點）；點回起點、雙擊左鍵或按 `Enter` 立即自動封閉為有填色的多邊形（繪製中按 `Backspace` 退回上一點、`Esc` 取消）。畫完後可於右側屬性面板或右鍵選單切換 **「封閉多邊形 / 開放折線」**，或進入 **「編輯頂點 (`Edit Points`)」** 模式拖曳橘色頂點、點擊邊線中點新增頂點或 `Alt + 點擊` 刪除頂點；存成 `.pptx` 時輸出為標準向量路徑，在 PowerPoint（手繪多邊形）與 Google Slides（折線 `Polyline`）中皆原生可編輯。
* **6 種直線／曲線磁吸連接線**：從工具列「連接線/箭頭」插入直線、單向/雙向直線箭頭、曲線、單向/雙向曲線箭頭。拖曳連接線兩端圓點靠近任一圖形時，目標圖形會浮現 **8 個磁吸控制點** 自動鎖定；日後移動或縮放該圖形時，連接線會**自動跟隨延伸與重算弧度**。

### 特色 3：公版母片、外部 `.pptx` 一鍵匯入公版與 6 組佈景主題
* **6 組商務佈景主題**：點選頂部 **「佈景主題」**，可一鍵切換「活力亮橘、經典深藍、森林翡翠、極簡石板灰、勃艮第暖金、深色黑曜」6 組專業色票，並可選擇套用至 **「全部投影片」** 或 **「僅目前投影片」**。
* **公版版面設定視窗**：從「套用版面 -> 公版母片設定」或「佈景主題 -> 自訂主題色盤」進入設定，可統一規範標題／內文的中英字體、字級與色彩、頂／底／左側裝飾色條、角落品牌 Logo 圖片、頁尾文字與自動頁碼（新增或重排投影片時頁碼自動重編為 `1..N`）。
* **從外部 `.pptx` 匯入公版**：可直接選擇公司現有的 `.pptx` 簡報範本，自動擷取其配色、字型、裝飾色條與 Logo 套用為本份簡報的 7 大標準公版。

### 特色 4：主畫布左鍵拉框多選、群組拖曳與 6 向對齊／2 向均分
* **兩種快速多選方式**：
  1. **滑鼠左鍵拉框圈選**：在投影片白色空白處或外圍深灰底板按住滑鼠左鍵拖曳拉框，**碰到元件邊框即選中**（自動排除背景裝飾與頁碼，不誤觸母片）；按住 `Ctrl + 拉框` 可分次疊加圈選。
  2. **`Ctrl + 滑鼠左鍵` 點選**：逐一加入或取消選取特定元件；`Ctrl+A` 可一鍵全選本頁所有一般元件。
* **同步拖曳與微調**：拖曳任一已選元件即可整批同步移動（含智慧中心對齊紅線與外部連接線連動）；鍵盤 `方向鍵` 可微調 `1px`、`Shift + 方向鍵` 每次移動 `10px`。
* **右側「已選取元件」批次排版專區**：選取 2 個以上元件時，右側面板自動切換為多選專區，提供 **6 向物件對齊**（靠左/水平置中/靠右/靠上/垂直置中/靠下）、**2 向畫布置中**、**3 個以上元件水平／垂直等距分佈**，以及批次更改填滿色、邊框色、中英字體、文字色與圖層順序。

### 特色 5：全簡報跨元件尋找與取代 (`Ctrl+F` / `Ctrl+H`)
按下 `Ctrl+F`（尋找）或 `Ctrl+H`（取代），即可展開懸浮搜尋列：
* **完整搜尋範圍**：一次掃描全簡報每一頁的 **文字方塊、幾何圖形文字、表格儲存格、商務圖表（標題／類別／數列名稱）與演講者備忘稿**。
* **安全防呆設計**：搜尋 `$100`、`(A+B)` 等特殊符號不會出錯；取代時嚴格保留段落原本不同的局部粗斜體與色彩樣式；自動保護母片頁碼不被誤改；若執行「全部取代」，只需按一次 `Ctrl+Z` 即可單步完整復原。

### 特色 6：列印與匯出浮水印設定 (`Ctrl+P`)
按下 `Ctrl+P` 或點選「檔案 -> 列印簡報」，會先開啟雙欄式 **「列印與浮水印設定」** 視窗（右側提供即時預覽與頁碼切換）：
* **文字／圖片雙模式**：文字浮水印內建 5 組商務範本膠囊（如「機密文件」、「內部傳閱」、「草稿版本」）；圖片浮水印可選取本機圖片或一鍵套用公版母片 Logo，並支援灰階刷淡與縮放。
* **6 種排版與雙圖層**：支援單一置中、滿版 3x3 交錯網格與四個角落，可調不透明度（`5% ~ 80%`）、旋轉角度與 **「頂層覆蓋 / 底層浮印」**。
* **專業列印控制**：支援 **「略過首頁封面」**、自訂列印頁碼範圍（如 `1-3, 5`）、勾選「同步套用至匯出檔案 (PDF/PNG/JPG/SVG)」，並可選擇「直接匯出 PDF」或進入系統列印視窗（自動支援**橫向一頁一張滿版**與**直向一頁上下兩張講義模式**）。
* **零污染隔離**：浮水印設定僅保留於當次軟體執行期間，絕不會寫入或污染您的原始 `.pptx` 檔案。

## 5. 跨平台相容性診斷器與「重製助手」

當您開啟別人寄來的 `.pptx` 檔案時，GoSLIDEEDIT 會在背景自動執行雙平台把關：

1. **狀態列相容性徽章**：
   * 顯示 `[PASS]` 相容通過徽章，表示整份簡報符合雙平台交集規範。
   * 若顯示相容性提示數量，點擊底部狀態列徽章即可展開診斷清單，查看是「字型映射」、「單邊轉場/動畫已自動降級為淡出」、「使用了本機系統字型」或「有元件超出畫布邊界」，並可點選定位或 **一鍵自動修復**。
2. **防誤覆寫保護**：開啟外部簡報若觸發自動相容性正規化，分頁標籤會標示未儲存圓點並**暫停自動儲存**，確保您檢視確認並主動按 `Ctrl+S` 後才覆寫磁碟檔案。
3. **不相容元件視覺快照與「重製助手」**：若外部 `.pptx` 含有 PowerPoint 專屬 SmartArt、內嵌原生 Excel 圖表或複雜群組物件，系統會在原座標位置自動擷取 **2x 高解析乾淨 `.png` 圖片快照**（加上虛線警示角標），確保畫面完整不缺漏。點選該元件後，右側 **「不相容元件重製助手」** 會列出提取出的原始文字與數據，讓您複製或一鍵在旁生成標準可編輯文字方塊、表格或商務圖表。

### 常見問題 (FAQ)

* **Q1：為什麼選單裡找不到 PowerPoint 的「轉化 (Morph)」、路徑動畫，或雲端字型（如 Aptos、Roboto）？**
  * A：因為這些特效或字型屬於單一平台獨佔，在另一平台（例如 Google Slides 或離線 PowerPoint）開啟時會失效或造成文字溢框。GoSLIDEEDIT 刻意僅保留雙平台共同支援的 4 種轉場、8 種動畫與 15 款安全字型，確保您交付的每一份 `.pptx` 零走樣。
* **Q2：在字型選單選用了電腦裡的「本機系統字型」，存成 `.pptx` 給同事會怎樣？**
  * A：在您的電腦上預覽、簡報播放或匯出 `.pdf` / `.png` 時會直接呈現該本機字型；但當儲存為跨平台 `.pptx` 時，系統會自動將其映射為最接近的 15 款安全字型之一，避免同事或 Google Slides 開啟時因為沒裝該字型而整頁亂掉。
* **Q3：插入 `.webp` 或 `.svg` 圖片後，存檔時會遺失嗎？**
  * A：不會。封裝進 `.pptx` 時，系統會自動於離線環境將 `.webp` 與 `.svg` 轉換為高解析 `.png` 嵌入簡報中，確保舊版 PowerPoint 與 Google Slides 都能正常顯示。
* **Q4：全軟體視窗或選單打開後想快速退回怎麼辦？**
  * A：在任何下拉選單、右鍵選單、公版設定／列印浮水印對話框、尋找列、文字輸入框或全螢幕播放模式下，直接按下 **`Esc`** 鍵即可逐層返回上一畫面。
